- 最新规则扫描覆盖当前待提交文件及 245 个可达 Git 对象，未命中个人域名、私钥头、常见提供商 Token 或 JWT 格式。这不是凭据不存在的绝对保证，不覆盖远端缓存、日志、附件及任意格式密码。

- 仍需关注：元数据及封面代理只有实例内限流；部分平台使用宽松域名匹配；iframe 未加 sandbox；服务端批量字段/请求体限制不足；本地与 Vercel PATCH 字段范围不一致。公开源码不会自动开放云端权限，但上线需保留强同步密码和用量告警。
